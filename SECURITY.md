# Segurança e Relato de Problemas

Este repositório documenta governança comunitária. Ele não recebe relatos públicos de vulnerabilidades com detalhes sensíveis.

## Não Publique em Issues

- Dados pessoais.
- Credenciais.
- Tokens.
- Prints com informações privadas.
- Detalhes exploráveis de falhas em sistemas reais.
- Links para dados vazados.
- Instruções de abuso ou invasão.

## Como Relatar

Use os canais oficiais de moderação da K0Sec para relatar problemas sensíveis. Se o problema envolver um repositório específico, descreva o impacto de forma geral e aguarde orientação antes de publicar detalhes técnicos.

## Escopo Educacional

A K0Sec é uma comunidade educacional. Conteúdos práticos devem envolver somente máquinas próprias, laboratórios controlados, sistemas deliberadamente vulneráveis, plataformas educacionais ou ambientes com autorização expressa.

## Resposta

A equipe pode remover conteúdo, ocultar comentários, solicitar edições ou limitar discussões públicas quando houver risco para membros, terceiros ou sistemas.
