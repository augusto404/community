# Eventos

Espaço para propostas, planejamento e registros de eventos da K0Sec.

## Tipos de Atividades

- Apresentações introdutórias.
- Workshops.
- Grupos de estudo.
- Laboratórios guiados.
- CTFs educacionais.
- Encontros regionais.
- Discussões sobre carreira e certificações.

## Como Propor

Abra uma issue usando o template de proposta de evento. Descreva objetivo, público recomendado, formato, pré-requisitos, cuidados éticos e resultado esperado.

## Registros

Somente registre um evento como realizado depois que ele acontecer. Não invente datas, números de participantes, apoiadores ou resultados.
