# Relatórios

Espaço para relatórios públicos de atividades da K0Sec quando houver algo realizado e revisado.

## Um Relatório Pode Conter

- Contexto da atividade.
- Objetivo.
- Formato.
- Aprendizados.
- Pontos de melhoria.
- Próximos passos.

## Cuidados

- Não exponha dados pessoais de participantes.
- Não invente métricas.
- Não publique prints privados.
- Não apresente planejamento futuro como resultado concluído.
